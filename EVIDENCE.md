# Public Technical Overview

CrossGen is represented here as a company project case study. [View the public product](https://www.crossgen-tech.com).

| Area | Publicly described engineering contribution |
|---|---|
| Web interface | Social and content workflow surfaces |
| Service integration | Connecting application workflows to external services |
| Desktop integration | Coordinating member-owned execution with the web application |
| Delivery | Hosting and operational integration work |

The relationship can be read as a web application coordinating service integrations and a member-side execution component. This is a high-level description, not a deployment specification. Company source, private architecture decisions, and unpublished implementation details are excluded.
